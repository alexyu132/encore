## 3. Extruder installation

### Non-printed parts:
|Item|Qty|
|--|--|
|M3 bolt (length depends on extruder)|3|
| NEMA 17 motor |1|
| Bowden extruder (BMG or similar) |1|

Mount the extruder motor in the location shown on the rear panel. Recommended: face the stepper motor wires toward the left side.

![alt text](image-75.png)

Install the extruder body on the opposite side and use the extruder bolts to secure it to the motor and rear panel.
![alt text](image-76.png)

## 4. PSU installation
### Printed parts:
|Item|Qty|
|--|--|
|Bottom enclosure|1|

### Non-printed parts:
|Item|Qty|
|--|--|
|Meanwell LRS-150-24 or generic 6A 24V LED PSU |1|
| M3x6mm bolt |3|

Install the PSU in the location shown, with the terminals facing to the left.
![alt text](image-77.png)

Secure using 3 M3x6mm bolts. Note that the genuine Meanwell PSU is thinner than the generic Aliexpress units. There are multiple sets of bolt holes on the bottom enclosure to accommodate both types.
![alt text](image-78.png)
